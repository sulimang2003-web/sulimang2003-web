# قائمة مراجعة ما قبل الإطلاق — المتطلبات التركية

> ⚖️ هذه قائمة تنظيمية إرشادية وليست استشارة قانونية. **لا يُفترض تحقق الامتثال تلقائياً.**
> يجب مراجعتها مع محامٍ ومحاسب (Mali Müşavir) في تركيا قبل استقبال طلبات حقيقية.

## 1. التسجيل التجاري والضريبي
- [ ] وجود سجل تجاري/ضريبي ساري (Vergi levhası) يغطي البيع عن بُعد/الإلكتروني (رمز النشاط NACE المناسب).
- [ ] تحديد نسبة KDV الصحيحة لكل فئة منتجات (الإعداد في اللوحة مرجعي فقط) وآلية إصدار الفاتورة: **e-Arşiv Fatura / e-Fatura** عبر مزود معتمد.
- [ ] عرض بيانات البائع كاملة في الموقع: الاسم التجاري، العنوان، الهاتف، البريد، MERSİS no، رقم الضريبة.

## 2. ETBİS (Elektronik Ticaret Bilgi Sistemi)
- [ ] تسجيل الموقع والنطاق (domain) في ETBİS لدى وزارة التجارة قبل/فور بدء النشاط، وتحديث البيانات عند تغيّرها.
- [ ] عرض شعار/رمز التحقق ETBİS (QR) في تذييل الموقع بعد التسجيل.

## 3. حماية المستهلك والبيع عن بُعد
(قانون 6502 TKHK + Mesafeli Sözleşmeler Yönetmeliği)
- [ ] **Ön Bilgilendirme Formu** (نموذج المعلومات المسبقة) يُعرض قبل تأكيد الطلب.
- [ ] **Mesafeli Satış Sözleşmesi** كامل، وموافقة صريحة عليه (مربع الموافقة موجود في صفحة الإتمام — النص الحالي مسودة).
- [ ] حق الانسحاب 14 يوماً، الاستثناءات (مثل الملابس الداخلية لأسباب صحية)، ومهلة رد المبلغ 14 يوماً.
- [ ] إرسال نسخة العقد للعميل عبر وسيط دائم (بريد/SMS) — يتطلب إضافة خدمة بريد (انظر خارطة الطريق).
- [ ] الأسعار شاملة الضرائب وتكلفة الشحن واضحة قبل التأكيد (مطبّق).
- [ ] لائحة الإعلانات التجارية والممارسات غير العادلة: أسعار "قبل الخصم" يجب أن تكون حقيقية (لائحة تخفيضات الأسعار — الحد الأدنى السابق خلال 30 يوماً).

## 4. KVKK (قانون حماية البيانات 6698)
- [ ] **Aydınlatma Metni** (نص الإفصاح) نهائي ومنشور — المسودة في `/policies/privacy`.
- [ ] **Açık Rıza** منفصلة للتسويق والكوكيز غير الضرورية (شريط الموافقة موجود ولا يحمّل Pixel/GA قبل القبول).
- [ ] تقييم التسجيل في **VERBİS** حسب الحجم والعتبات المعمول بها.
- [ ] **نقل البيانات للخارج** (Supabase/Vercel خارج تركيا): مراجعة المادة 9 بعد تعديلات 2024 (عقود قياسية/إشعار الهيئة) أو اختيار منطقة استضافة مناسبة.
- [ ] سياسة الاحتفاظ وحذف البيانات، وآلية الرد على طلبات أصحاب البيانات (المادة 11) خلال 30 يوماً.
- [ ] إذن **İYS** (نظام إدارة الرسائل التجارية) قبل أي رسائل تسويقية عبر SMS/بريد/اتصال.

## 5. الدفع
- [ ] التعاقد مع مؤسسة دفع مرخّصة من BDDK/TCMB (مثل iyzico أو PayTR أو بوابة بنكية) — البنية جاهزة في `src/lib/payments`.
- [ ] استخدام صفحة/iframe الدفع المستضافة لدى المزود مع 3D Secure — لا تمر بيانات البطاقة عبر خوادمنا.
- [ ] سياسة الدفع عند الاستلام ورسومها إن وُجدت.

## 6. واتساب وMeta
- [ ] رقم واتساب Business حقيقي في الإعدادات (القيمة الحالية placeholder).
- [ ] Meta Pixel/Conversions API فقط بعد الموافقة وإضافة ذكرها في نص الكوكيز.
- [ ] عند الانتقال لـ WhatsApp Cloud API (رسائل تلقائية): حساب Meta Business موثّق وقوالب معتمدة.

## 7. تقني قبل الإطلاق
- [ ] إنشاء مشروع Supabase + تطبيق الـ migration + إنشاء حساب المالك وإضافته لجدول `admins`.
- [ ] تعيين `SESSION_SECRET` قوي، وكلمات مرور قوية، وتعطيل وضع الديمو (ضبط متغيرات Supabase).
- [ ] نطاق خاص + HTTPS، وتحديث `NEXT_PUBLIC_SITE_URL`.
- [ ] استبدال الصور التجريبية واللوغو وجدول المقاسات بالبيانات الحقيقية.
- [ ] نسخ احتياطي يومي للقاعدة (Supabase PITR أو النسخ المجدول).
