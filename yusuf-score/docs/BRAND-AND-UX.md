# YUSUF SCORE — تحليل العلامة، الهوية البصرية، وتجربة المستخدم

> ملاحظة: لم تصلنا الصور المرجعية (الحساب، اللوغو، المنتجات) ضمن هذه الجلسة. التحليل التالي مبني على المعطيات المكتوبة
> (متجر فعلي في الفاتح/إسطنبول، حساب إنستغرام موثّق @yusufscore بنحو 40 ألف متابع، ملابس رجالية). أي معلومة غير مؤكدة معلّمة بـ ⚠️.

## 1. تحليل العلامة

| المحور | القراءة |
|---|---|
| الموقع | الفاتح — منطقة تجارية كثيفة بزوار عرب وأتراك، ثقة "المحل الحقيقي" ميزة تنافسية يجب إبرازها رقمياً. |
| القناة الأقوى | إنستغرام (≈40k ⚠️ حسب المراجع). معظم الزيارات ستأتي من الموبايل عبر رابط البايو والستوري. |
| سلوك الشراء | جمهور معتاد على السؤال والطلب عبر الرسائل/واتساب ← واتساب يجب أن يكون مسار طلب أساسياً وليس ثانوياً. |
| الفجوة | انتقال من "حساب إنستغرام + DM" إلى علامة ذات تجربة تسوق منظمة: كتالوج، مقاسات، مخزون، تتبع حملات. |
| التموضع المقترح | **Accessible Luxury** — مظهر فاخر هادئ (Quiet Luxury) مع أسعار سوق الفاتح، وخدمة شخصية. |

## 2. الهوية البصرية المقترحة (مطبّقة في الكود)

- **الألوان** (`src/app/globals.css`):
  `ink #0E0E0D` · `charcoal #1C1B1A` · `graphite #2A2826` · `ivory #F6F1E8` · `paper #FBF8F2` · `bone #E9E2D5` · `gold #B8995A` (هادئ، للّمسات فقط) · `sale #8C3B2E`.
- **الخطوط**: عناوين لاتينية *Cormorant Garamond* (سيريف أزياء) + عناوين عربية *Amiri*؛ نصوص *Jost* + *IBM Plex Sans Arabic*.
- **اللوغو**: Wordmark مؤقت `YUSUF SCORE` بتباعد حروف واسع + سطر ذهبي `ISTANBUL · FATIH`، وأيقونة تطبيق `YS`.
  ⚠️ يُستبدل بملف اللوغو الرسمي (SVG) في `src/components/store/logo.tsx` و`public/icons/`.
- **الحركة**: ظهور تدريجي ناعم عند التمرير، تكبير بطيء للصور، شريط Marquee، احترام `prefers-reduced-motion`.
- **التصوير المطلوب**: صور 4:5 بخلفية عاجية/رمادية موحدة، صورة "lookbook" داكنة للـ Hero، صور تفاصيل (قماش/أزرار).

## 3. خريطة الموقع (Sitemap)

```
/                → توجيه تلقائي إلى /ar أو /tr (حسب لغة المتصفح/الاختيار السابق)
/{ar|tr}         الرئيسية: Hero · وصل حديثاً · الفئات · الأكثر مبيعاً · القصة · المزايا · إنستغرام · زيارة المتجر
  /shop          المتجر: فلترة (فئة/مقاس/لون/سعر) · ترتيب · بحث · ?tag=new|bestseller
  /product/:slug المنتج: معرض · مقاس/لون · مخزون لكل مقاس · جدول مقاسات · سلة · واتساب · مشابه
  /cart          السلة
  /checkout      الإتمام (بيانات + عنوان + شحن + كوبون + ملخص → واتساب)
  /about /contact /faq
  /policies/{shipping|returns|privacy|terms}
/admin           لوحة الإدارة (محمية)
  /orders /orders/:id /products /products/new /products/:id /categories /coupons /settings
/api/v1/products, /api/v1/products/:slug, /api/v1/categories   ← API عامة للتطبيق المستقبلي
/manifest.webmanifest · /sw.js · /sitemap.xml · /robots.txt
```

## 4. رحلة المستخدم الأساسية (Instagram → طلب)

1. ستوري/بايو برابط UTM (يُنشأ من لوحة الإدارة ← الإعدادات) → يُحفظ المصدر 30 يوماً.
2. صفحة المنتج: اختيار لون ← مقاس (المقاسات النافدة معطّلة) ← "أضف للسلة" أو "اطلب عبر واتساب" مباشرة.
3. رسالة واتساب جاهزة: الاسم، الكود، المقاس، اللون، الكمية، السعر، والرابط.
4. أو: السلة ← الإتمام ← يُسجَّل الطلب في القاعدة (حجز المخزون + رقم طلب YS-xxxxx) ← تُفتح محادثة واتساب بالملخص.
5. صاحب المحل يؤكد عبر واتساب، ويغيّر الحالة من اللوحة (الإلغاء يعيد المخزون)، ويرسل للعميل رسالة الحالة بنقرة.
